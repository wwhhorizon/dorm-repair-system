# 单人分工与贡献说明

## 项目身份

本项目仓库账号为wwhhorizon，按一人一组实施。不虚构四人小组，不将角色测试账号当作项目成员。姓名、学号、班级和组号由本人确认后在正式提交材料填写。

## 职责

本人承担需求梳理、架构与数据库设计、浏览器界面、后端业务、AI集成、测试、部署、版本管理及答辩。项目使用Codex辅助生成和修改代码、文档、测试与演示脚本；不把AI辅助输出描述为未经辅助的独立手写成果。本人应阅读并确认实现、理解关键规则并完成现场说明。

## 版本管理

使用feat/repair-system开发分支，验证后集成main。提交记录以实际产生时间记录，不补造十周历史。源码、测试、数据库脚本、配置和文档统一入库，.env、运行数据库和会话不入库。CI运行结果与提交SHA关联。

## 本人后续事项

- 确认课程允许本题的业务替换和单人组安排。
- 实际需求访谈或试用反馈，记录真实参与者及日期。
- 核对AI辅助使用是否符合课程要求，能解释分类、权限及状态转换。
- 按要求签到、现场展示和答辩。
- 填写正式身份信息及实验报告。实验报告当前按要求暂缓。
