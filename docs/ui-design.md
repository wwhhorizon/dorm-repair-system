# 界面设计

界面围绕学生报修、管理员派单和维修人员处理展开。保留中科大高新校区实景，以深蓝导航、白色工作区和蓝色按钮组成工作台。

## 信息布局

登录页用校园夜景建立地点感；进入系统后，照片收为页幅，主要空间用于工单。总览依次呈现筛选、数量、当前待办和统计。管理员优先看到待受理报修，维修人员看到未完成任务，学生看到自己的报修。空环境显示数量零和提交入口，不显示空图表。

## 文案

按钮使用“提交报修”“确认派单”“提交完工”等动作名称。工单详情把操作放在历史前面。分类建议直接显示类别，匹配分数与模型版本放入可展开的详情。操作日志显示中文名称。模型评估和部署配置放在技术文档。

## 视觉与交互

- 主要操作 #2455C7；导航 #16344B；背景 #F3F6F9；正文 #16344B；次要文字 #52677C。
- 中文使用微软雅黑 UI／苹方，数字采用等宽数字。正文与表单保留明确层级。
- 桌面使用左侧导航；390px 手机端改为横向导航，统计两列、工单与图表单列。
- 保留键盘焦点、表单标签、自动填充、错误提示、忙状态及减少动画偏好。
- 登录、总览、列表、详情和手机总览通过 axe-core 指定 WCAG 规则检查。

## 设计工具

本次使用 [Impeccable](https://github.com/pbakaus/impeccable) 改写文案及梳理工作台层级；结合 frontend-design 和 Web Interface Guidelines 检查布局与交互。视频采用 [Product Feature Video](https://github.com/akmishra56/product-video-skill) 的实际录屏、逐章配音和素材交付方法。
