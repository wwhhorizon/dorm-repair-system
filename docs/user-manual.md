# 用户操作手册

## 登录与注册

打开系统首页，输入用户名和密码。学生可点击注册创建账号；维修人员和管理员需要获得相应邀请码。用户名3～40字符，密码至少10位并含字母和数字。演示账号和随机密码按README从本地初始化输出或`.env`读取。

## 学生

1. 点击“提交报修”，选择楼栋及房间，描述故障，选择类别，可附一张现场图片。
2. 提交后进入详情，查看工单编号、当前状态、AI建议和处理记录。AI暂未返回时工单已经创建，可正常等待处理。
3. 在“报修工单”查询历史。可筛选楼栋、类别、状态及日期，支持分页。
4. 未派单工单可以取消；活跃工单可补充说明和图片。
5. 待验收时检查维修结果，确认验收或填写原因申请返修。
6. 完成后提交一次1～5星评价。在账号设置中可修改密码。

图片上传失败时，先确认工单已创建，进入详情补传，避免重新创建同样的问题。请尽量描述故障，不上传包含个人隐私的照片。

## 管理员

1. 在“用户与宿舍”维护楼栋和房间，查看账号并启用/停用非管理员用户。
2. 在工单列表打开问题，参考AI建议确认分类，选择维修人员和未来预约时间。
3. 已派单或处理中的任务可以重派，但必须填写原因。重新打开详情以获取最新版本，避免409冲突。
4. 在总览按楼栋、类别和日期查看报修量、状态、趋势和评价，页面自动刷新统计。
5. 在工单列表按当前条件导出CSV，可用电子表格软件打开。导出时间使用UTC。
6. 在操作日志查看登录、派单、分类和导出等记录。

## 维修人员

1. 在“维修任务”查看当前分配给自己的任务，核对预约时间、位置、故障描述及照片。
2. 点击开始维修进入处理中。
3. 完成后填写处理说明，可上传维修结果图片，再提交完工。
4. 学生要求返修时，根据返修说明继续处理并再次提交完工。

## 提示与异常

409通常表示状态已变化；关闭详情并重新打开后再操作。401表示需要重新登录。实时连接断开时页面会尝试重连；也可以点击总览刷新。未出现AI建议不影响管理员人工分类。账号被停用后不能继续访问，联系管理员处理。
