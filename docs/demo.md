# 演示脚本

演示视频由真实浏览器操作录制，文件deliverables/demo.webm。脚本在每个阶段展示解说字幕并保留阅读时间，全片至少320秒。无音轨；字幕说明角色与处理步骤。录屏运行于演示数据库，不冒充真实后勤业务。

## 复现

先启动本地服务并初始化演示账号，再安装Playwright Chromium：

```powershell
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe scripts/browser_verify.py --record
```

脚本使用本地.env中的演示密码；需要与已有演示账号密码一致。视频不显示密码明文或邀请码。脚本创建新工单，依次操作真实后端，不能用静态页面替代推理与状态转换。

## 分镜

1. 系统首页与三种角色说明。
2. 学生登录查看总览。
3. 选择宿舍并填写漏水报修。
4. 工单创建和处理记录。
5. 管理员查看实际AI建议和模型分数。
6. 确认类别，安排维修人员与时间。
7. 维修人员查看任务并开始。
8. 提交维修说明，进入待验收。
9. 学生验收并评价。
10. 第二名学生无法读取前一名学生的工单。
11. 管理员实时看板及筛选说明。
12. CSV导出、用户和宿舍管理。
13. 审计日志、交付与移动端界面。

现场可补充返修和过期版本409场景，使用测试报告解释并发、AI失效和输入校验。实验报告不包含在本次交付中。
